# CampusFlow — Smart College Schedule & Workload Optimizer

## Problem Statement
College students manage classes, assignments, exams and commitments across different sources. It can be difficult to identify schedule conflicts, overloaded days and usable study windows.

## Target Users
College students managing academic schedules and deadlines.

## Scope
A Python command-line application that stores academic data, detects conflicts, calculates a project-defined workload score, finds free study windows and performs what-if simulations.

## Functional Modules
1. Schedule management and conflict detection
2. Workload analysis
3. Study-window planning
4. What-if simulation
5. JSON persistence

## Out of Scope
GUI/mobile app, machine learning prediction, medical/psychological diagnosis, cloud accounts and automatic college-portal synchronization.
